# 大肥鱼拟人插件 · 参数说明

> 配置文件：`<你的 AstrBot>/data/plugins/astrbot_plugin_human_sim/config.json`（示例数据在 `astrbot-win/AstrBot-4.29.3/data/`）
> 本文所有「当前值」取自 2026-11-06 线上配置。
> 改完参数后：在中枢面板点该插件的**重载 / 重启**（只改这里的 json 不会热生效）。

**单位约定**

| 写法 | 含义 |
| --- | --- |
| 概率 | `0 ~ 1`，`0.2` = 20%，`0` = 永不触发，`1` = 必触发 |
| 秒 / 分钟 / 小时 | 按参数名后缀算，没有小数 |
| 时刻 | `0 ~ 23` 的整点，`end_hour` **不含**（`9` 和 `22` = 9:00 到 21:59） |
| 限额填 `0` | 视为「不限」，不是「禁止」 |

## 一、先看这 5 个（90% 的「它怎么不说话 / 怎么话这么多」都在这里）

| 参数 | 当前值 | 作用 |
| --- | --- | --- |
| `enabled` | `true` | 拟人行为总开关。关掉后不主动说话，但 **@ 仍由 AstrBot 主流程正常回复** |
| `watch_groups` | 9 个群 | 只在这些会话里工作，格式 `大肥鱼QQ:GroupMessage:群号`；没列进来的群完全不参与 |
| `ai_decide` | `true` | `true` = 由模型判断「这句想不想接」；`false` = 退回旧的纯随机插话 |
| `ai_decide_probability` | `0.35` | 每条消息先抽一次「值不值得想一想」，抽中才叫模型。**这是话量最敏感的旋钮** |
| `night_frequency_scale` | `0.0` | 夜间（22:00–08:59）所有**自主**发言概率的乘数，`0` = 夜里完全不自言自语 |

---

## 二、一分钟到底能说几句？（限流全在这）

### 1. 先明确：没有「同 IP 限流」

QQ / NapCat 这一层不提供 IP，插件也没有按 IP 计数。真正防封靠的是下面这些**按群、按人、按进程**的闸门，外加发送前排队。

### 2. 当前线上实际限额

| 层级 | 参数（当前值） | 上限 | 超了会怎样 |
| --- | --- | --- | --- |
| 每群·自主接话 | `ai_decide_per_minute`（1）+ `ai_decide_cooldown_seconds`（120） | 每群每分钟 1 条，且两次之间至少 2 分钟 | 咽回去，只留日志 |
| 每群·旧随机插话 | `interject_per_minute`（1）+ `interject_cooldown_minutes`（120） | 只在不走 AI 的旧模式生效 | 跳过 |
| 每群·冷场捞人 | `group_idle_per_minute`（1） | 每分钟 1 条 | 跳过 |
| 每群·同人反复 @ | `sender_rate_max_directed`（3）/ `sender_rate_window_seconds`（60）→ `sender_rate_cooldown_seconds`（180） | 同一人 60 秒内最多 3 次定向消息 | 之后 **180 秒内连 @ 也不回**（专门掐两只 AI 互 @） |
| 全进程·所有群自主发言 | `global_per_minute`（2）+ `global_gap_min`/`max`（90/180 秒） | 每分钟最多 2 条，且相邻两条至少隔 90–180 秒 | 全局防封闸直接丢弃 |
| 同群·所有机器人合计 | `shared_minute_cap`（12） | 含正常回复在内，每群每分钟最多 12 条（跨进程共享） | 多机器人互相接话时自动闭麦 |
| 同会话·连说两句 | `send_min_gap_seconds`（3） | 刚开过口 3 秒内不再发 | 压住 |
| 出站排队 | 内置 1.6–3 秒 | 同会话消息串行，不会同一秒连发 | 自动排队 |

**所以「每分钟最大发言次数」不是某个单值，而是一串下限相乘：**
`全局 2 条/分钟` ∩ `每群 1 条/分钟` ∩ `相邻两条隔 90–180 秒` ∩ `同群合计 12 条/分钟`。
现在这组数字的体感是：**没被点名时，同一个群两次自主接话至少隔 2 分钟；全机器人合计大约 2–3 分钟才有一句。**
（例外：刚被 @ / 点名后的跟进窗口内，按 `followup_min_gap_seconds`=10 秒算，不受 2 分钟冷却约束。）

### 3. 想调松 / 调紧

| 目标 | 改这些 |
| --- | --- |
| 更活跃 | 调高 `ai_decide_probability`，调小 `global_gap_min/max`、`ai_decide_cooldown_seconds` |
| 更安静 | 反过来；或直接把 `ai_decide_per_minute`、`global_per_minute` 降为 1 |
| 某个群不设限 | 把该群 umo 加进 `unlimited_groups`（**只绕每分钟限额和全局闸，冷却仍要遵守**） |
| 立刻闭嘴 | `/禁言 30`（默认时长看 `mute_default_minutes`），`/解禁` 恢复 |

## 三、宵禁（22:00–09:00）里被 @ 会回吗？

**会。** 分清两类行为：

| 行为 | 宵禁期间 |
| --- | --- |
| 被 **@** | ✅ 必回。@ 走 AstrBot 正式流水线，根本不经过本插件的概率、限额、时段判断 |
| **引用** 它的消息 | ✅ 必回（算「点名」，绕过概率 / 每分钟 / 冷却 / 夜间系数） |
| 叫它的**名字** | ✅ 必回——**前提是 `bot_names` 有填**。当前 `bot_names = ["大肥鱼"]`，叫「大肥鱼」或 @ 都算点名 |
| 指令（`/禁言` 等） | ✅ 随时可用 |
| 自主搭话、冷场捞人、复读、+1、巡查、主动私聊 | ❌ 夜间系数 `0.0`，全部关闭 |
| 定时问候 | ✅ 不受夜间系数影响（23:00 的「晚安」槽位是特意保留的） |

**唯一的「@ 也不回」情况**：同一人 60 秒内第 4 次 @（触发 `sender_rate_*` 限流）、本群被 `/禁言`、或账号本身被平台风控。

### 4.3 AI 自主决策（主线）

| 参数 | 当前值 | 说明 |
| --- | --- | --- |
| `ai_decide` | `true` | 用模型判断要不要接话 |

| `decision_check_interval_seconds` | `8` | 同一群两次「要不要叫模型」的最小间隔（省 token） |

| 参数 | 当前值 | 说明 |

| `audience_max_size` | `2000` | 人数上限 |

| `audience_activity_min` | `0.35` | 冷清群的最大补偿系数 |
| `audience_activity_max` | `2.0` | 冷场小群的上限系数（最终还会被 1.6 封顶） |

## 五、现象 → 该看哪个参数

| 现象 | 优先检查 |
| --- | --- |
| 一句都不说 | `enabled`、`watch_groups` 是否包含该群、当前是否 22:00–09:00、`night_frequency_scale=0`、`ai_decide_probability` 是否过低、`global_gap_max` 是否过大 |
| 说得太多 | `ai_decide_probability`、`ai_decide_per_minute`、`global_per_minute`、`global_gap_*` |
| 半夜突然冒一句 | 多半是 23:00「晚安」问候（`greeting_slots`），不是自主发言 |
| @ 了还不回 | 群被 `/禁言`、同一人 60 秒内 @ 超过 3 次、`bot_names` 为空导致「叫名字」不算点名 |
| 两个机器人互相刷屏 | `shared_minute_cap`（同群合计上限）、`sender_rate_*`（互 @ 熔断） |
| 只发表情不说话 | 正文被判空后走了表情兜底，看 `face_probability` / `sticker_probability` |
| 总是复读同一句 | `repeat_probability`、`repeat_cooldown_seconds`、`interest_repeat_min_weight` |

## 六、改法示例

只让某个群更活跃（其他不动）：

```json
{
  "unlimited_groups": ["大肥鱼QQ:GroupMessage:1000000001"],
  "global_gap_min": 30,
  "global_gap_max": 60
}
```

开启「叫名字也算找我」（会绕过宵禁与每分钟限额，慎用）：

```json
{ "bot_names": ["大肥鱼", "肥鱼", "小鱼"] }
```

关掉夜间一切主动行为、只回 @：

```json
{ "night_frequency_scale": 0.0, "start_hour": 9, "end_hour": 22 }
```
