# 低配与降级部署

不是每台机器都能全量跑。这份文档按**能力**拆开讲：完整形态是什么、降级形态是什么、具体改哪个开关、损失了什么。

先给结论：**降级不等于跑不起来**。收发消息和回复这条主链路在任何一档都能用，降掉的都是「增强项」。

## 档位速查

| 档位 | 跑什么 | 资源门槛 | 有 | 没有 |
| --- | --- | --- | --- | --- |
| **L0 只有核心** | hub / model / store / brain | 2G 内存，无 GPU，模型走云端 API | 模型路由、记忆、控制台 | 聊天通道、语音、桌宠、拟人 |
| **L1 只聊 QQ** | L0 + AstrBot + NapCat + 少量插件 | 建议 8G 内存 | 群聊/私聊回复、拟人、文字表情、手动表情库 | 微信、本地语音、桌宠、QQ 空间 |
| **L2 全功能无 GPU** | L1 + 微信桥 + 全部插件 | 16G 内存 | 除本地语音外全部 | CosyVoice2（自动回退 edge-tts） |
| **L3 全量** | 全部 + CosyVoice2 + 桌宠 | NVIDIA 显卡 2~4G 显存 | 全部 | — |

`README.md` 里那张「和普通 QQ 机器人的区别」是按 **L3** 写的。降到 L1/L2 时，其中几条卖点并不存在，部署前请先对号入座。

## 表情包：AI 主动收录 → 自己管库

这是最常被问的一个。完整形态下插件会在群聊/私聊里自己判断收图、下载、算指纹、进收藏库；机器弱、磁盘小、或者不想让机器人自动存别人的图时，可以整段关掉，改成手动维护。

### 关掉自动收录

在 `astrbot_plugin_sticker_pack` 的配置里改：

| 配置 | 改成 | 效果 |
| --- | --- | --- |
| `fav_enabled` | `false` | 群/私聊收图的两个入口直接返回，**不下载、不建收藏库、不跑指纹**，等于彻底关掉自动收录 |
| `follow_up_probability` | `0` | 关掉「发完文字后让 AI 挑一张」的流程，省掉每条回复的额外模型调用 |
| `fav_vision_check` | `false` | 没有视觉模型时关掉粗筛（默认失败会自动放行，但会白等一次调用） |
| `inject_index` | 保持 `false` | 把整库索引塞进 system prompt 会显著吃 token，不要开 |

### 保留什么

- `map.txt` 索引 + `pack_dir` 指向的图片目录照常工作
- AI 回复里写 `:情绪词:` 依然会按**文字相似度**从你手动的库里挑图 —— 这一步是纯本地计算，不额外调用模型
- `send_meme` 工具仍然可用，只是候选只剩手动库

### 损失什么

- 群友发的图不再自动进库，没有「新图新鲜度加成」，库不会自己长大
- 没有收藏库的查重、审核、每日上限那一套

### 手动管理工具

`astrbot_plugin_sticker_pack/tools/` 下有几个脚本，可以配定时任务跑：

| 脚本 | 用途 |
| --- | --- |
| `purge_static.py` | 清理没有被索引引用的图 |
| `fix_gif_ext.py` | 修正动图扩展名（导入后常见） |
| `bench_pool.py` | 跑一遍推荐，看哪些情绪词老是空手 |
| `sync_qq_faces.py` | 同步 QQ 黄脸表到本地 |

索引格式见该插件 README 与 `main.py` 顶部说明。

## 语音：本地克隆 → edge-tts

- **不装** CosyVoice2（安装器里跳过编号 7），或机器没有 NVIDIA 显卡
- 结果：自动回退 edge-tts，**朗读还在**
- 损失：音色克隆、说话与唱歌同一套声线、情感控制

CosyVoice2 大约要 2~4G 显存，装不上时不用反复重试，直接按降级用就行。

## 桌宠：不装

- **不装** dsh-pet（安装器里跳过编号 8），也不启 `relay/pet-relay.js`
- 桌宠只是展示层，不参与对话；不装不影响聊天、语音、QQ 空间
- 前提提醒：dsh-pet 依赖 DeepSeek Harness，而 DSH 目前未公开发布，多数机器本来就走这条降级

### 装了桌宠但没有海草 / 背景泡泡

这两层是同一套背景层，由 `bubbleBackdropEnabled` 控制。在第二台机器上装完却看不到，按顺序查：

```powershell
.\pet\dsh-pet\install.ps1 -Backdrop check   # 只读：打印版本与四个背景层字段
.\pet\dsh-pet\install.ps1 -Backdrop on      # 打开（数量为 0 会改成 9，非法取值拉回默认）
```

- dsh-pet 低于 **0.4.1** 没有这层渲染代码，改配置无效，要重跑完整 `install.ps1`
- `bubbleBackdropEnabled: false` 整层隐藏；`bubbleBackdropCount: 0` 只关泡泡，海草仍在
- 配置在 `%USERPROFILE%\.dsh\dsh-pet\main-config.jsonc`；脚本只改这几个字段，注释保留
- 桌宠每 30 秒拉一次配置，等半分钟；不生效就右键桌宠重启

## 微信桥：只接 QQ

- 微信桥走 Windows UIA，必须有**已登录、窗口可见**的桌面会话；服务器、无桌面环境、或者不想担风控风险，就整块不装
- 损失：微信侧收发
- QQ 侧完全不受影响

## 模型：别指望小机器跑大模型

- 没有 GPU：`astrbot_plugin_provider_router` 把群聊切到云端 API 或小参数 Ollama
- 模型越小，拟人效果越差：插话时机、接话质量、表情选择都会变钝
- 语音、桌宠之外的「聪明程度」基本由这里决定，不是靠插件堆出来的

`services/model/providers.json` + 环境变量（如 `DEEPSEEK_API_KEY`）配云端通道。

## 视频 / 字幕 / 转写：整包不装

- 不装 `services/audio`、`video`、`subtitle` 与相关插件
- `web_lookup` 仍然能搜网页、抓正文、解析视频的标题与评论；只是没有字幕和音频转写
- `web_lookup` 自身也能降压：`concurrency` 降到 1~2、`max_results` 5、`keep_n` 3、`max_chars` 800

## 拟人：可全关，也可调轻

- 不装 `human_sim`：就是普通问答机器人，每条消息都回，不主动说话
- 装了但嫌吵：调低插话概率与冷场开话头概率、缩短活动时段、开夜间降频
- 相关搭配插件（humanizer / speaker_tag / group_window / basic_tools）都是增强项，缺谁就少一层，不会导致启动失败

## 最低能跑到什么程度

- **只跑核心**：`tools/windows/start-core.bat`，然后浏览器开 `http://127.0.0.1:23408`
- **只聊 QQ**：`.\install.bat -Select 1,2,3,4,5`（环境 + 核心 + AstrBot + 插件 + NapCat），跳过 6 微信桥、7 语音、8 桌宠
- 两种都不需要显卡

## 降级部署时要写清楚的事

如果你把降级形态部署给别人用，建议在说明里标明档位，否则用户会拿 L3 的描述去要求 L1 的行为 —— 比如找不到「主动私聊」「本地语音」「桌宠」，其实不是坏了，是没装。
