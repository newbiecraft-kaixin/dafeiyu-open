# AI 使用说明

这份文件说明本项目与 AI 的关系，方便使用者、平台审核和上游项目判断。

## 项目本身是 AI 应用

运行时需要调用大模型：本地 Ollama（例如 `qwen2.5vl:3b`）或任何兼容 OpenAI 接口的云端服务。模型权重不随仓库分发，需要你自己下载或配置 API Key。

## 开发过程中

代码与文档有 AI 工具参与，提交前由维护者修改并测试，维护者对提交内容负责。提交历史里没有把 AI 工具列为 co-author 的提交，可以用 `git log` 核对。

本文件不做「零 AI 参与」的声明，也不给出「AI 生成比例」这类无法核实的数字。如果你要据此判断（部分项目或托管平台会限制 AI 生成代码），请看提交历史和代码本身。

## 介绍或转载本项目时

Hacker News、V2EX 等社区对 AI 生成文本有明文规定（V2EX 的处罚是至少 259200 秒的锁）。请用你自己的话写，不要直接粘贴 README 或模型生成的摘要。
